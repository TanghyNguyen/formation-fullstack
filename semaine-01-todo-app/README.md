# Todo App

[Live demo](https://formation-fullstack-1pw4.vercel.app/)

Here's a TodoApp that I built during my first weeks of learning React.

## Features

- Add a task.
- Mark a task as finished.
- Delete a task.
- Remaining task counter.
- A message will appear when the task list is empty.

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4

## Run locally

```bash
pnpm install
pnpm dev
```
